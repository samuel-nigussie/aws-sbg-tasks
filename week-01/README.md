# Diabetes Data Processor

A small Python data-processing application that cleans and analyzes diabetes data using Pandas and NumPy.

## Features

- Loads diabetes data from a CSV dataset.
- Inspects dataset structure and missing values.
- Removes duplicate records.
- Handles missing values using median and mode imputation.
- Uses NumPy to calculate descriptive statistics.
- Visualizes the distribution of patient ages.
- Exports the cleaned dataset to CSV.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab
